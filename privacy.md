# Privacy Policy - Rclone Backup

Last updated: 10 November 2026

Rclone Backup is a personal tool used by one person, its owner, to copy the owner's own backup files to the owner's own Google Drive account.

What it accesses: the tool asks for the Google Drive "drive.file" permission only, so it can create and manage the backup files that it uploads itself. It cannot see any other files in the account.

What it collects: nothing. It does not collect, store, share or sell personal data about any other person. It has no other users, no advertising and no analytics.

How data is handled: backup files are encrypted before they are uploaded. The access token Google issues is stored only on the owner's own server and is never shared.
